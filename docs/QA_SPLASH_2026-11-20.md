# DaunPOS — QA Splash Screen 2.1.1

Tanggal: 20 November 2026

## Implementasi
- Memakai logo asli DaunPOS yang sudah ada pada `app/src/main/res/drawable-nodpi/logo_daunpos.jpg`.
- Menghapus seluruh teks penjelasan panjang dan elemen kategori yang tidak perlu pada layar pembuka.
- Menampilkan nama aplikasi dan tagline singkat: "Kasir praktis untuk usaha Anda".
- Menampilkan tiga ikon ringkas: Transaksi, Stok, Laporan.
- Menampilkan dua aksi utama: "Mulai Setup Toko" dan "Masuk dengan PIN".
- Tidak menggunakan scroll; layout dipusatkan dan ukurannya adaptif terhadap ruang layar.
- Tidak mengubah callback atau alur navigasi tombol yang sudah ada.

## Perangkat dan hasil
Perangkat uji: vivo V2324A, resolusi 900 × 1600 px, density asli 320 dpi (sekitar 450 × 800 dp).

Pengujian tambahan dilakukan pada perangkat yang sama dengan density override:
- 360 dp lebar: semua konten dan kedua tombol terlihat.
- 320 dp lebar: semua konten dan kedua tombol terlihat, termasuk tombol kedua; tidak ada elemen yang perlu di-scroll.
- Density dikembalikan ke 320 dpi setelah pengujian.

## Uji interaksi
- Tombol "Mulai Setup Toko" membuka langkah pemilihan kategori bisnis.
- Tombol "Masuk dengan PIN" membuka halaman PIN pemilik.
- QA dilakukan melalui package sementara `com.daunpos.app.preview`, sehingga aplikasi produksi tidak ditimpa.
- Package preview dihapus setelah pengujian. Package produksi `com.daunpos.app` tetap terpasang pada versi 2.1.0 dan datanya tidak diubah.
